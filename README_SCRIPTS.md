# FlowDev-AI 服务控制与运维脚本套件使用指南

本项目为全栈架构（**Next.js 14 前端** + **FastAPI 后端**），为提升本地开发与运维体验，已将所有**启动、停止、重启、状态检测、日志监控**整合为一站式脚本套件。

---

## 快速使用

### 方式 1：一站式统一管理器 (推荐，双击即用)

双击根目录下的 **`manage.bat`**（或 **`flowdev.bat`**），将打开交互式控制台菜单：

```text
================================================================================
                FlowDev-AI 智能全栈开发流 - 一站式服务管理控制台                
================================================================================
请选择管理操作:
  [1] 一键启动全部服务 (后端 :8000 + 前端 :3000)
  [2] 一键停止全部服务 (释放端口 8000 与 3000)
  [3] 一键重启全部服务 (平滑重启并执行健康检查)
  [4] 查看服务运行状态 (端口占用、PID、内存、响应延迟)
  [5] 查看实时后端日志 (FastAPI :8000)
  [6] 查看实时前端日志 (Next.js :3000)
  [7] 查看前后端日志快照
  [0] 退出控制台

请输入数字选项 [0-7]:
```

---

### 方式 2：独立快捷脚本 (双击或命令行)

在 Windows 资源管理器中可直接双击对应的 `.bat` 文件，或在命令行中运行：

| 快捷脚本 | 命令调用 | 功能说明 |
| :--- | :--- | :--- |
| **`start.bat`** | `.\manage.ps1 start` 或 `.\start.bat` | 一键同时启动后端与前端，显示启动端口、实时进度与健康检查面板 |
| **`stop.bat`** | `.\manage.ps1 stop` 或 `.\stop.bat` | 一键树级关闭前后端进程，彻底释放 8000 和 3000 端口 |
| **`restart.bat`** | `.\manage.ps1 restart` 或 `.\restart.bat` | 一键停止并重新拉起服务，等待端口就绪并刷新健康状态 |
| **`status.bat`** | `.\manage.ps1 status` 或 `.\status.bat` | 查询当前运行端口、PID、内存占用及 API 连通性 |
| **`logs.bat`** | `.\manage.ps1 logs` 或 `.\logs.bat` | 查看或实时追踪前后端最新运行日志 |

## 启动效果与日志说明

### 1. 启动进度反馈
执行启动时，脚本将依次展示 5 阶段进度：
- `[1/5] 检查运行环境与前置依赖`：检测 Python 3.10+、FastAPI/Uvicorn 依赖库、Node.js、pnpm 及 `.env` 配置文件。
- `[2/5] 检查服务端口占用`：自动检测 8000 与 3000 端口，若发现冲突自动清理旧进程。
- `[3/5] 启动后端服务 (FastAPI)`：后台启动 Uvicorn，并将控制台输出重定向至 `logs\backend.log`。
- `[4/5] 启动前端服务 (Next.js)`：后台启动 Next.js 开发服务器，并将控制台输出重定向至 `logs\frontend.log`。
- `[5/5] 健康检查与连通性验证`：动态轮询 `http://127.0.0.1:8000/api/health` 与 `http://localhost:3000`，确认服务完全响应。

### 2. 服务启动完成看板
启动成功后输出完整卡片：

### 3. 日志目录与文件
所有日志均存放在项目根目录下的 **`logs\`** 文件夹中：
- **`logs\backend.log`**：FastAPI 后端 Uvicorn 的标准输出与报错日志（包含请求耗时、SSE 流推送信息、Agent 执行日志）。
- **`logs\frontend.log`**：Next.js 前端编译、热重载以及 Webpack/Turbopack 输出日志。
- **`logs\pids.json`**：服务运行时记录的进程 ID 与端口映射。

## 常见问题排查

1. **双击批处理闪退？**
   - 批处理文件已内置 `chcp 65001` (UTF-8) 与末尾 `pause` 逻辑，即使报错也会保留控制台窗口以便查看错误信息。
2. **端口被其他软件占用？**
   - 脚本已内置智能清理逻辑，执行 `stop.bat` 或再次执行 `start.bat` 会自动释放被占用的 8000 和 3000 端口。
